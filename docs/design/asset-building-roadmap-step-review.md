# 資産形成ロードマップ ステップ見直し検討メモ

- ステータス: 検討中
- 作成日: 2026-11-28
- 対象: 学習ステップの順序・分け方・ゴール
- 関連資料: [要件定義](../requirements/beginner-nisa-all-country-investing.md)、[画面設計](asset-building-roadmap.md)

## 1. この資料の目的

現行の5ステップに対する見直しで合意した構成、残る執筆事項、次の作業を記録する。現行案は比較のために残し、3章以降を見直し後の方針として扱う。

検討中も、金融知識の学習を目的とすること、特定の商品・証券会社や投資開始を勧めないこと、元本割れ等のリスクを明示することを維持する。

## 2. 現行のステップ

| 順序 | ステップ | 現在の扱い |
|---|---|---|
| 1 | 家計と投資目的を確認する | 生活費・近く使うお金、目的・期間、値下がりへの備えをロードマップ上で確認 |
| 2 | NISAの仕組みを知る | NISAの記事を読む |
| 3 | 投資信託とインデックス投資を知る | 投資信託・指数・商品差・費用・リスクを学ぶ |
| 4 | 長期・積立・分散を考える | 考え方と限界を学び、ドル・コスト平均法は任意の補足とする |
| 5 | 始める前・始めた後に備える | 積立額、値下がり時の行動、見直し方を確認 |

現在の道筋は「家計の確認 → 制度 → 投資対象・仕組み → 投資方法 → 開始前後の確認」。到達点は投資開始ではなく、NISAで全世界株式インデックスファンドの積立を自分で検討するための知識と確認事項を把握すること。

## 3. 見直し後の構成案

この構成では、最初に投資目的を確認し、次に投資目標を設定する。その後に家計の現状を把握し、投資の前提となる家計づくりへ進む。

| 順序 | 検討するステップ | 内容の例 |
|---|---|---|
| 1 | 投資目的を確認する | なぜ投資をするのかを考える |
| 2 | 投資目標を設定する | 投資で達成したい目標を考える |
| 3 | 家計の現状を把握する | 現在の家計状況を確認する |
| 4 | 家計の収支を改善する | 固定費の削減など |
| 5 | 高金利負債を把握し、対応を考える | カードローン、リボ払いなどの残高・金利・返済条件を確認する |
| 6 | 生活防衛資金の考え方を知る | 必要額の考え方と準備方法を学ぶ。目標額を貯め終えることは、次へ進む条件にしない |
| 7 | 投資の基礎を知る | 既存の「長期・積立・分散」記事を先に読み、次に「インデックス投資」記事で仕組みや投資対象を学ぶ |
| 8 | NISAの仕組みを知る | 制度の役割と注意点を学ぶ |
| 任意（主ルート後） | 証券口座の開設を検討する | 学んだうえで、必要なら開設を検討する |

この案では、投資の制度や商品を学ぶ前に、目的・目標と家計の準備を扱う。

### 主ルートと任意の次の行動

主ルートは1〜8の8段階とし、**投資の基礎 → NISAの仕組み**の順に学ぶ。NISAは投資商品ではなく制度上の枠組みなので、先に投資対象やリスクなどの基礎を理解し、その後で制度の役割や注意点を学ぶ。

NISAを学んだ後、必要と判断した人には証券口座の開設を任意の次の行動として示す。口座開設は主ルートの段階に数えず、これを含めて10段階にはしない。投資の基礎に含める個別テーマや各段階の完了条件は引き続き検討する。

投資開始後の運用や見直しは、今回の主ルートには含めない。主ルートは投資を始める前に、自分で積立を検討できるところまでとする。

### 決定した対象者

主な対象者は、**NISAで全世界株式インデックスファンドの積立を検討する初心者**とする。

### 決定した最初の2段階

最初に「投資目的を確認する」、次に「投資目標を設定する」を別々の段階として置く。

### 決定した到達点

学習の到達点は、**NISAで全世界株式インデックスファンドの積立を自分で検討できること**とする。投資を始めること、商品を購入すること、証券口座を開設すること自体は必須のゴールにしない。

### 決定した投資の基礎の範囲

NISAの前に学ぶ主ルートは、既存の「長期・積立・分散」記事、続いて「インデックス投資」記事とする。投資方法の基本的な考え方を先に学び、その後にインデックス投資の仕組みや対象を確認する。株式・債券など資産種類ごとの記事は、必須ではなく補足として扱う。

### 決定した新規ページ方針

新しい記事は1ページだけ作り、タイトルは「投資を考える前の家計整理」とする。構成は、①手取り収入と毎月の支出を書き出す、②住居・通信・保険・サブスクリプションなどの固定費を見直す、③負債の残高・金利・返済条件と相談先を確認する、の3部とする。具体的な節約額や投資に回す額は指定せず、全員に投資前の完済を一律に指示しない。生活防衛資金は既存の `/learn/emergency-fund` を利用し、投資の基礎とNISAも既存記事を活用する。投資目的・目標は、独立記事ではなくロードマップ上の問いやチェック項目で扱う。具体例や参照先など、その他の説明内容は未決定。

## 4. 構成上のガイド

- 投資目的の確認と投資目標の設定は、別々の段階にする。
- 生活防衛資金は、必要額の考え方と準備方法を学ぶ。個人別の目標額を貯め終えることは、次の学習へ進む条件にしない。
- 投資の基礎を学んでからNISAを説明し、特定の商品・証券会社や投資開始を勧めない。
- 主ルートはNISAを学ぶ8段階で完了する。証券口座の開設は段階番号を付けない任意の次の行動とする。
- 投資開始後の運用や見直しは今回の主ルートに含めない。
- 高金利負債は状況と返済条件を確認し、対応を考える内容とする。全員に投資前の完済を一律に求めない。
