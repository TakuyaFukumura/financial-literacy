# 資産形成ロードマップ 画面設計

- ステータス: Draft
- 作成日: 2026-11-28
- 対応要件: [資産形成ロードマップ 要件定義](../requirements/beginner-nisa-all-country-investing.md)

## 1. 設計方針

- 初期版は「NISAで全世界株式インデックスファンドの積立を検討する」1ルートに絞る。
- 投資目的、投資目標、家計の準備、投資の基礎、NISAの順に学ぶ。投資開始や口座開設をゴール・必須条件にしない。
- 主ルートは4つのエリアと8つの地点で構成する。証券口座の開設は主ルート完了後の任意の行動として分けて表示する。
- 家計の現状把握・収支改善・高金利負債を扱う記事を1ページだけ新設し、ロードマップから各セクションへ直接移動できるようにする。
- 投資を始めることや特定商品を買うことをゴールにせず、自分で検討するための知識と確認事項を把握することをゴールにする。

## 2. ページ構成と導線

### 共通ヘッダー

ロードマップへの文字リンクをヘッダーに常設する。ロードマップの未閲覧・既読にかかわらず全ページで表示し、サイト名とテーマ切替の操作に並べる。

```text
[お金の学び場]         [ロードマップを見る] [テーマ切替]
```

### トップページ

既存のヒーローとテーマ一覧を維持し、新規記事「投資を考える前の家計整理」を資産形成の基本カテゴリに追加する。ロードマップへは共通ヘッダーから移動できる。

### ロードマップページ

- URL: `/asset-building-roadmap`
- ページタイトル: `資産形成ロードマップ | お金の学び場`
- 導入部に対象者、ゴール、学習目的（個別の投資助言・商品推奨ではないこと）を記載する。
- 4つのエリアを順に並べ、主ルートを8地点で構成する。
- 地点3〜5から新規記事 `/learn/pre-investment-household` の該当セクションへ移動できるようにする。
- 地点7では「長期・積立・分散」から「インデックス投資」の順に読み進める。ドル・コスト平均法や株式・債券などは、主ルートとは区別した任意の補足とする。
- 地点8のNISAの後に、証券口座の開設は必要な場合だけ検討する任意の行動として示す。9番目の地点は作らない。
- 最終地点の後に、テーマ一覧へ戻るリンクと学習目的の注意書きを置く。

## 3. ロードマップのワイヤーフレーム

デスクトップでは道筋を縦に進み、地点カードを左右交互に配置する。以下の図は順序と内容を示す概略であり、実際の画面では道がカーブして地点をつなぐ。

```text
資産形成ロードマップ
NISAで全世界株式インデックスファンドの積立を検討するために
購入や口座開設をゴールにせず、目的から順に知識と家計を整理します。

目的と目標を整理する
  ① 投資目的を確認する ── ロードマップ内の問い
  ② 投資目標を設定する ── ロードマップ内の問い
                         │
家計の土台を整える
  ③ 家計の現状を把握する ── [家計整理記事の該当箇所]
  ④ 家計の収支を改善する ── [固定費見直しの該当箇所]
  ⑤ 高金利負債への対応を考える ─ [負債確認の該当箇所]
  ⑥ 生活防衛資金の考え方を知る ─ [生活防衛資金の記事]
                         │
投資の基礎を知る
  ⑦ 長期・積立・分散 → インデックス投資
                         │
制度を知る
  ⑧ NISAの仕組みを知る ──────── [NISAの記事]

主ルート完了後：必要なら証券口座の開設を検討（任意）
[テーマ一覧へ戻る]
```

## 4. 8地点の表示内容

| 地点 | 表示タイトル | 内容・操作 |
|---|---|---|
| 1 | 投資目的を確認する | なぜ投資を考えるのかを整理する。回答は入力・保存しない。 |
| 2 | 投資目標を設定する | 目標額や使う時期を考える。具体的な投資額は指示せず、目標は見直せることを伝える。 |
| 3 | 家計の現状を把握する | `/learn/pre-investment-household#household-status` へ移動し、手取り収入と毎月の支出の整理方法を確認する。 |
| 4 | 家計の収支を改善する | `/learn/pre-investment-household#fixed-costs` へ移動し、固定費などの契約・利用状況を見直す観点を確認する。 |
| 5 | 高金利負債への対応を考える | `/learn/pre-investment-household#debts` へ移動し、残高・金利・返済条件、相談先を確認する。投資開始前の一律完済は求めない。 |
| 6 | 生活防衛資金の考え方を知る | `/learn/emergency-fund` へのリンク。必要額の考え方と準備方法を学ぶ。貯め終えることを次へ進む条件にしない。 |
| 7 | 投資の基礎を知る | `/learn/long-term-installment-diversified` を先に読み、続けて `/learn/index-investing` へ進む。各記事は利益や損失回避を保証しないと説明する。 |
| 8 | NISAの仕組みを知る | `/learn/nisa` へのリンク。非課税制度であり、元本保証ではないことを短く紹介する。主ルートの最終地点。 |

地点1・2の確認項目は利用者の家計情報などを入力させず、回答を保存しない。地点3〜5は同じ新規記事の異なるセクションへリンクする。記事の主導線は次の地点とし、任意の補足や関連記事は別ラベルで表示する。

地点8の後には任意行動のカードを置く。「証券口座を開設する場合は、各金融機関の公式案内で条件を確認する」旨を示すが、開設先の比較・推奨、申込手順、投資開始の指示は行わない。

## 5. 視覚・レスポンシブ設計

- 既存サイトのアンバー系背景、白いカード、エメラルド系アクセント、角丸・枠線のスタイルを踏襲する。
- 共通ヘッダーではサイト名、ロードマップリンク、テーマ切替の操作を並べる。狭い画面でもリンク文言を表示し、他の操作と重ならないようにする。
- 道筋は地点を通るカーブした道路として表現する。道路の縁と中央線を付け、番号付きマーカーと合わせて道らしさを出す。外部画像や地図ライブラリは導入せず、装飾用のインラインSVGとCSSで描画する。
- デスクトップでは、S字状の道に沿って地点カードを左右交互に配置する。エリア見出しで学習のまとまりを示す。
- モバイルでは、道を画面左側で緩やかに曲げ、地点カードを右側に一列で配置する。カード幅を優先し、横スクロールを発生させない。
- ライト／ダークモードの両方で、道の線、地点番号、カード境界、リンクの視認性を保つ。
- ホバーだけで情報を表示しない。キーボードフォーカスが明確に見えるようにする。

## 6. 操作性・アクセシビリティ

- 主ルートは順序付きリスト（`ol`）とし、4つのエリアを見出し（`h3`）、各地点をその下位見出し（`h4`）で示す。視覚上の道筋とDOM上の読み上げ順を一致させる。
- 道路のSVGや中央線などの装飾は読み上げ対象外とする。順序は`ol`、地点番号、見出しでも伝える。
- 記事への地点はリンクとして実装し、クリック範囲とフォーカス表示を十分に確保する。
- 記事内アンカーの見出しには安定したIDを付け、直接移動後も対象の見出しが識別できるようにする。
- 確認項目は利用者の家計情報を入力させず、回答を保存しない。チェック済み状態や学習進捗の保持も行わない。
- 任意リンクには「任意」と明記し、主ルートと視覚的に区別する。

## 7. 初期実装で再利用するもの

- 既存の共通ヘッダーにロードマップリンクを追加し、トップページを含む全ページから利用できるようにする。
- 既存記事 `/learn/emergency-fund`、`/learn/long-term-installment-diversified`、`/learn/index-investing`、`/learn/nisa` を地点6〜8で再利用する。
- `/learn/pre-investment-household` を新規作成し、既存の `LearningTopicPage` を使って家計把握・固定費・負債の3セクションを表示する。
- 初心者タグはロードマップ上の記事に表示するが、リンクや検索フィルターにはしない。
- `LearningTag` に必要なタグを追加し、記事共通レイアウトのタグ・関連記事・戻る導線を活用する。
- ロードマップ対象記事にはロードマップへの戻り先と、主ルート上の位置・次の学習先を表示する。NISAの記事では8/8と主ルート完了を示し、次の学習段階へのリンクは表示しない。
- ロードマップ自体は固定コンテンツとし、ログイン、データベース、進捗保存、個別の利用者状態を導入しない。
