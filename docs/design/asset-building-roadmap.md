# 資産形成ロードマップ 画面設計

- ステータス: Draft
- 作成日: 2026-11-28
- 対応要件: [資産形成ロードマップ 要件定義](../requirements/beginner-nisa-all-country-investing.md)

## 1. 設計方針

- 初期版は「NISAで全世界株式インデックスファンドの積立を検討する」1ルートに絞る。
- 既存記事を道筋の中心に置き、家計と開始前後の確認はロードマップ内の短いチェック項目にする。新しい独立記事は作らない。
- 学習順を「道」と5つの地点で表現する。装飾的なイラストより、どこから始め、次にどこへ進むかの分かりやすさを優先する。
- 投資を始めることや特定商品を買うことをゴールにせず、自分で検討するための知識と確認事項を把握することをゴールにする。

## 2. ページ構成と導線

### 共通ヘッダー

ロードマップへの文字リンクをヘッダーに常設する。ロードマップの未閲覧・既読にかかわらず全ページで表示し、サイト名とテーマ切替の操作に並べる。

```text
[お金の学び場]         [ロードマップを見る] [テーマ切替]
```

### トップページ

トップページには追加カードを設けず、既存のヒーローとテーマ一覧をそのまま残す。ロードマップには共通ヘッダーから移動できる。

```text
お金のことを、基礎から学ぼう。
暮らしに役立つお金の知識を……

テーマから学ぶ
[既存のテーマカード一覧]
```

### ロードマップページ

- URL: `/asset-building-roadmap`
- ページタイトル: `資産形成ロードマップ | お金の学び場`
- 共通ヘッダーの記事リンク、記事内の「ロードマップに戻る」リンクから移動する。
- 導入部に対象者、ゴール、学習目的（個別の投資助言・商品推奨ではないこと）を記載する。
- 4つのエリアを順に並べ、主ルートを5地点で構成する。
- 地点4から「ドル・コスト平均法」の記事へ進める任意リンクを、主ルートから枝分かれする補足として表示する。
- 最終地点の後に、テーマ一覧へ戻るリンクと学習目的の注意書きを置く。

## 3. ロードマップのワイヤーフレーム

デスクトップでは道筋を縦に進み、地点カードを左右交互に配置する。以下の図は順序と内容を示す概略であり、実際の画面では道がカーブして地点をつなぐ。

```text
資産形成ロードマップ
NISAで全世界株式インデックスファンドの積立を検討するために
投資を始める前に、仕組みやリスクを順番に確認する道筋です。
ここでのゴールは、購入することではなく、自分で検討する材料を知ることです。

家計の土台を整える
  ① 家計と投資目的を確認する ── ロードマップ内のチェック項目
                         │
制度と投資対象を知る     │
  ② NISAの仕組みを知る ──────── [NISAの記事を読む →]
                         │
  ③ 投資信託とインデックスを知る ─ [記事を読む →]
                         │
投資方法を考える         │
  ④ 長期・積立・分散を考える ─── [記事を読む →]
          └─ もっと詳しく: ドル・コスト平均法（任意）
                         │
始める前に備える         │
  ⑤ 始める前・始めた後に備える ── ロードマップ内のチェック項目

[テーマ一覧へ戻る]
```

## 4. 5地点の表示内容

| 地点 | 表示タイトル | 内容・操作 |
|---|---|---|
| 1 | 家計と投資目的を確認する | 生活費や近い将来に使う資金を投資資金と分けているか、投資の目的・期間、値下がりへの備えを自分で振り返る短いチェック項目を表示する。入力・保存はしない。 |
| 2 | NISAの仕組みを知る | `/learn/nisa` へのリンク。非課税制度であり、元本保証ではないことを短く紹介する。 |
| 3 | 投資信託とインデックス投資を知る | `/learn/index-investing` へのリンク。リンク先で全世界株式インデックスファンドの対象指数、商品ごとの差、費用・為替・価格変動リスクを確認できるようにする。 |
| 4 | 長期・積立・分散を考える | `/learn/long-term-installment-diversified` へのリンク。ドル・コスト平均法は主ルート上の地点にせず、同記事から `/learn/dollar-cost-averaging` へ任意で進める補足リンクとして表示する。 |
| 5 | 始める前・始めた後に備える | 積立額を無理なく続けられるか、値下がり時にどう考えるか、見直しや停止が必要な場合をどうするかを振り返る。入力・保存はしない。 |

地点2〜4のリンク先記事には、既存の「次に読む」導線を維持したうえで、ロードマップに戻る導線を追加する。記事内の次の記事とロードマップ上の次地点は別のナビゲーションとして表示し、混同を避ける。

現在、地点4の記事の「次に読む」はドル・コスト平均法を指している。初期ルートでは任意の補足とするため、このリンクは「次に読む」ではなく「任意の補足」と分かるラベルで表示する。

## 5. 視覚・レスポンシブ設計

- 既存サイトのアンバー系背景、白いカード、エメラルド系アクセント、角丸・枠線のスタイルを踏襲する。
- 共通ヘッダーではサイト名、ロードマップリンク、テーマ切替の操作を並べる。狭い画面でもリンク文言を表示し、他の操作と重ならないようにする。
- 道筋は地点を通るカーブした道路として表現する。道路の縁と中央線を付け、番号付きマーカーと合わせて道らしさを出す。外部画像や地図ライブラリは導入せず、装飾用のインラインSVGとCSSで描画する。
- デスクトップでは、S字状の道に沿って地点カードを左右交互に配置する。エリア見出しで学習のまとまりを示す。
- モバイルでは、道を画面左側で緩やかに曲げ、地点カードを右側に一列で配置する。カード幅を優先し、横スクロールを発生させない。
- ライト／ダークモードの両方で、道の線、地点番号、カード境界、リンクの視認性を保つ。
- ホバーだけで情報を表示しない。キーボードフォーカスが明確に見えるようにする。

## 6. 操作性・アクセシビリティ

- 主ルートは順序付きリスト（`ol`）とし、4つのエリアは見出しで区切る。視覚上の道筋とDOM上の読み上げ順を一致させる。
- 道路のSVGや中央線などの装飾は読み上げ対象外とする。順序は`ol`、地点番号、見出しでも伝える。
- 記事への地点はリンクとして実装し、クリック範囲とフォーカス表示を十分に確保する。
- チェック項目は利用者の家計情報を入力させず、回答を保存しない。チェック済み状態や学習進捗の保持も行わない。
- 任意リンクには「任意の補足」と明記し、主ルートと視覚的に区別する。

## 7. 初期実装で再利用するもの

- 既存の共通ヘッダーにロードマップリンクを追加し、トップページを含む全ページから利用できるようにする。
- 記事は既存の `/learn/nisa`、`/learn/index-investing`、`/learn/long-term-installment-diversified` を再利用する。
- 初心者タグはロードマップ上の記事に表示するが、リンクや検索フィルターにはしない。
- `LearningTag` に「初心者」を追加し、ロードマップ上の記事と任意の補足記事で表示する。
- 記事共通レイアウトのタグ・関連記事・戻る導線の既存パターンを活用する。ロードマップ対象記事には「ロードマップに戻る」リンクを追加し、既存の「次に読む」リンクとは別にする。ドル・コスト平均法へのリンクは、地点4の記事で任意の補足と明示する。
- ロードマップ自体は固定コンテンツとし、ログイン、データベース、進捗保存、個別の利用者状態を導入しない。
